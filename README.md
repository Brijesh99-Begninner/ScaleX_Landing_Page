# ScaleX Landing Page

> India's Business Expansion Ecosystem

A single-page marketing website for **ScaleX**, built to communicate its mission of helping businesses scale through trusted, long-term partnerships. The site showcases ScaleX's portfolio, marketing, operational, and legal advisory partners in a clean, editorial-style layout.

## ✨ Features

- **Custom Typography System** — Cormorant Garamond paired with Inter for a premium, editorial feel
- **Refined Color Palette** — Deep Navy, Olive Green, and Warm White
- **Partner Showcase Grid** — Responsive card layout highlighting portfolio partners and specialized advisory partners (marketing, operational, legal)
- **Fully Responsive** — Optimized for desktop, tablet, and mobile viewports
- **Vanilla Stack** — No frameworks or build tools; pure HTML, CSS, and JavaScript

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5      | Page structure and semantic markup |
| CSS3       | Styling, layout, and responsive design |
| JavaScript | Interactivity and dynamic behavior |

## 🚀 Getting Started

### Prerequisites

No build tools or dependencies required — just a modern web browser.

### Running Locally

1. Clone the repository
   ```bash
   git clone https://github.com/Brijesh99-Begninner/ScaleX_Landing_Page.git
   ```
2. Navigate into the project folder
   ```bash
   cd ScaleX_Landing_Page
   ```
3. Open `index.html` directly in your browser, or serve it locally using a tool like VS Code's Live Server extension for the best experience (hot reload, no CORS issues).
